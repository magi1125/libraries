# 『Webアクセシビリティの教科書』を読める図書館

『具体例と解決策で学ぶ Webアクセシビリティの教科書』（伊原力也・太田良典 著、
ボーンデジタル、ISBN 978-4-86246-661-7）を所蔵している全国の図書館の一覧です。

https://magi1125.github.io/weba11y-libraries/

所蔵していない図書館には購入希望（リクエスト）を出せます。ページに書誌情報を
載せてあるので、お住まいの自治体の図書館に申し込んでみてください。

## データについて

- 公共・専門図書館: [カーリル図書館API](https://calil.jp/doc/api.html)
- 大学図書館: [CiNii Books](https://ci.nii.ac.jp/books/)
- 国立国会図書館: [国立国会図書館サーチ](https://ndlsearch.ndl.go.jp/)

毎週月曜に自動で全国を再照会して更新しています。生成スクリプトはローカルで
管理しています。図書館の蔵書は日々変わるため、実際の所蔵状況は各図書館で
ご確認ください。
